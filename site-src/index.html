Self-hosted ActivityPub SNS

自分の輪を、
自分でつくる。

自分ひとりのための、小さな SNS です。フォローした相手の投稿を時間順に読みながら、つながる相手と コミュニティを自分で選べます。

Takosumi で追加 → ローカルで試す 運用方法 GitHub

届く範囲は、
自分が広げた輪の中だけで、いいです。

アルゴリズムを、手放す。

タイムラインはおすすめ順に並べ替えません。自分がフォローした相手の投稿を、時間順に表示します。

輪は、小さくていい。

興味でつくる小さなコミュニティが、そのまま「届く範囲」になります。薄く広い繋がりより、濃くて小さな繋がりを大切にします。

居場所は、自分のもの。

セルフホストでは、運用先やデータの置き場所を自分で選べます。 ActivityPubに対応する別のサーバーとも、フォローや投稿を やり取りできます。

スマホでも、
自分の輪。

ホーム画面から開けば、タイムラインも、ストーリーも、DM も使えます。あなたのサーバーが、そのままポケットの中に入ります。

まず、手元で試す。

01 準備 リポジトリを取得して、Bunで依存関係を入れます
02 試す bun run dev:mockで画面と機能を確認します
03 運用先を選ぶ 管理ホストか、Cloudflareでのセルフホストを選びます

管理ホストでは deploy/takoform、Cloudflareで セルフホストする場合はルートの main.tf または wrangler.jsonc を使います。詳しい手順は デプロイガイドにあります。
