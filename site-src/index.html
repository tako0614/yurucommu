yurucommu

自分ひとりのための self-hosted ActivityPub SNS。 フォローした相手の投稿を時間順に読み、つながる相手と コミュニティを自分で選べる。

AGPL-3.0-only · github.com/tako0614/yurucommu · ActivityPub · Cloudflare Workers / Takoform

Takosumi で入れる ローカルで試す Docs GitHub

考え方

  • タイムラインは投稿時間順のみ — アルゴリズムによる並べ替えはない
  • 興味でつくるコミュニティが、そのまま投稿の届く範囲になる
  • データは自分のサーバーに置く — 運用先と置き場所を自分で選ぶ
  • ActivityPub 対応の別サーバーとも、フォローや投稿をやり取りできる

画面

ホーム

フォローした相手の投稿が新しい順に流れる。どこまで遡るかは自分次第。

ストーリー

キャンバスエディタで自由に描いて貼れる。投稿は 24 時間で消える。

表示の絞り込み

コミュニティ単位で、見る景色を輪の中だけに絞り込める。

モバイル

ホーム画面から開けば、タイムライン・ストーリー・DM が使える。

導入

Takosumi で入れる

導入画面に、入れる app と入れる先が表示される。内容を確認してそのまま導入できる。

install 画面を開く

ローカルで試す

リポジトリを取って依存を入れ、dev mock で画面と機能を確認する。 

$ git clone https://github.com/tako0614/yurucommu.git
$ cd yurucommu
$ bun install
$ bun run dev:mock
はじめかたを見る

自分のサーバーに建てる

管理ホストでは deploy/takoform、Cloudflare でセルフホストする場合はルートの main.tf または wrangler.jsonc を使う。
