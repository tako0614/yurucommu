最初の投稿

投稿画面を開き、文章や画像を共有するまでの流れを説明します。

投稿の作成

  1. 「投稿」を押す。スマートフォンでは、画面右下の丸い投稿ボタンを押す
  2. 開いた投稿画面に文章を入力する
  3. 必要に応じて公開範囲や画像・動画を設定する
  4. 右上の「投稿」を押す

画像・動画の添付

  1. 投稿画面の「画像・動画を追加」を押す
  2. 添付するファイルを選ぶ。1回の投稿に最大4件まで追加できる
  3. 必要であれば、画像の内容を伝える代替テキストを入力する
  4. アップロードが完了してから「投稿」を押す

公開範囲

投稿画面では、次の3つから公開範囲を選べます。

範囲 説明
公開 誰でも見ることができます
未収載 リンクを知っている人は見られますが、公開の一覧には載りません
フォロワー 自分をフォローしている人だけが見ることができます
個別に送りたいとき: ダイレクトメッセージは投稿の公開範囲ではありません。特定の相手だけに送りたい内容は、「メッセージ」画面から送信してください。

注釈を付ける

内容を読む前に注意を示したいときは、投稿画面で「注釈を追加」を選びます。入力した注釈が先に表示され、本文は読む人が開いて確認できます。

ストーリーを作る

ストーリーは、24時間で表示されなくなる短い投稿です。ホーム上部の「ストーリーを追加」から作成できます。

  1. 「ストーリーを追加」を押す
  2. 写真・動画・テキストなどを追加する
  3. 内容を整えたら「ストーリーズに投稿」を押す

表示時間は内容に合わせて自動で決まります。作成時に秒数を入力する必要はありません。
